MARATHON QUICK GUIDE

⚠️ RULE ZERO
If not sure something is allowed → treat it as NOT allowed.
Common sense, safety, fair play above all.
Deliberate rule-bending → disqualification from event.

🤖 ROBOT – BASIC CHECK
Autonomous only – no remote control during run.
Size: ≤ 25×25 cm, height: 5–15 cm, weight: ≤ 1 kg.
Must fit freely in control box (no pressure).
Safe construction: no damage to field, no dangerous parts.
Has clear Start & Stop button.

🔌 ELECTRONICS
Basic: 1 microcontroller, ≤ 4 motors, ≤ 4 sensors, only official EDU kit parts, no 3D prints, no modified parts.
Advanced: more freedom in electronics, but still safe & autonomous.
Prohibited: pneumatics, pullback motors, gases, voltage > 24 V anywhere.
🧪 TECHNICAL INSPECTION
First attempt: full inspection + short questions on program.
If team cannot explain the program → +20% time penalty.
If robot fails specs and team refuses to fix → disqualification from event.
Before every attempt: quick re-check for specs & autonomy.
At any moment, if robot is found non-autonomous / remote-controlled → immediate DQ.

🏟️ ARENA & LINE
White PVC field with a black line ≈ 1.8 cm.
Closed track: start & finish on same side.
At intersections: robot must follow the main straight line, not the crossing branch.
Robot must stay inside arena boundaries at all times.
⏱️ START & TIME
Robot placed before time sensor, in standby.
On whistle → Technician presses Start (or allowed remote).
Robot must start within 5 seconds.
Only in 1st attempt: one restart allowed if it fails to start.
Timer starts when robot passes the time sensor.
Max time per run: 3:00. Over 3:00 → record 180 s (0 points).
🏃 VALID / INVALID ATTEMPT
VALID attempt

Robot stays inside arena.
Robot follows the black line; short small deviations are OK if direction is correct.
Basic: robot clearly uses line-following sensors over/next to the line.
INVALID attempt → 0 / 180 s

Robot exits arena boundary.
Robot completely loses the line or goes in wrong direction.
Robot is immobilised.
Robot doesn’t start or exceeds 3:00.
Basic: navigation clearly not based on line-following.

🔁 COMPETITION FLOW
Total sport time: about 90 minutes.
Teams run in announced order; absent Technician = lost attempt.
Between attempts: teams may adjust robot/code, but no testing on main track.
Best of the Best – Top 8

After 90 minutes → Top 8 overall run again (pairs 1–8, 2–7, 3–6, 4–5).
Same rules; one restart allowed on start failure.
The time from this round = final time used for ranking.

🟥 DISQUALIFICATION (TEAM – EVENT)
Robot does not meet specs and team refuses to adjust.
Technician shows abusive / disrespectful / aggressive behavior.
Robot is remotely controlled (Bluetooth, Wi-Fi, any external device).

✅ / ❌ QUICK LIST
Allowed

Cleaning wheels with wet wipes / cleaning liquid & paper.
In categories that allow it: remote only to start (no control during run).
Prohibited
Parts that may damage other robots or the field.
Glue-based traction, sticky tapes leaving residue, suction cups, any adhesion trick.
Wheels/parts that can hold an A4 sheet (> 2 seconds).
Gases / canisters to boost speed.
Robot breaking into pieces during run → time = 180 s (0).
Any connection to external devices (PC / phone / tablet) during run.
Pneumatics, pullback motors, mechanical expansion of size during the match.
🏆 WINNERS
Winners per age category and per Marathon Basic / Marathon Advanced.
Final ranking by shortest valid time in Best of the Best.
Advanced multi-robot rule: if a team has more than one robot on the podium, it keeps only the highest place; lower places pass to the next teams in the overall ranking.
